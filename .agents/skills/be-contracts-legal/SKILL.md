# Contrats & documents juridiques — solopreneur belge

## Overview

Ce skill fournit des **templates et checklists** pour les documents juridiques courants
d'un solopreneur belge : contrats de prestation, CGV, NDA, mentions légales, conditions
d'utilisation. Il ne rédige pas les contrats à ta place — il te donne la structure, les
clauses essentielles, et une checklist de vérification avant signature. Pour toute
situation complexe ou litigieuse, **consulter un avocat**.

## When to Use

- « Je dois rédiger un contrat de prestation pour un client »
- « Quelles clauses mettre dans mes CGV ? »
- « On me demande un NDA, je le remple comment ? »
- « Quelles mentions légales sur mon site web ? »
- « Mon client veut modifier le contrat, est-ce que c'est risqué ? »

**Ne pas utiliser pour :**
- Création d'entreprise (statuts, acte notarié) → `be-company-setup`
- RGPD (politique confidentialité, cookies) → `be-rgpd-compliance`
- Facturation → `be-invoicing-peppol`
- Optimisation fiscale → consulter un avocat/fiscaliste

## Documents juridiques courants

### 1. Contrat de prestation de services

**Structure minimale** :
1. **Parties** : nom/dénomination, adresse, numéro BCE, qualité (prestataire/client)
2. **Objet** : description précise de la prestation
3. **Durée** : déterminée (date début/fin) ou indéterminée (avec préavis)
4. **Prix et conditions de paiement** : montant, échéances, modalités, pénalités de retard
5. **Obligations du prestataire** : diligence, moyens, résultat si garanti
6. **Obligations du client** : collaboration, fourniture d'informations, paiement
7. **Propriété intellectuelle** : qui détient les droits sur les livrables
8. **Confidentialité** : obligations de non-divulgation
9. **Responsabilité** : limitation, exclusion, assurance
10. **Résiliation** : conditions, préavis, conséquences
11. **Droit applicable et juridiction** : droit belge, tribunaux de [ville]

**Clauses critiques BE** :
- **Pénalités de retard** : loi sur les retards de paiement (B2B) — intérêts de plein droit
- **Propriété intellectuelle** : en l'absence de clause, c'est le prestataire qui détient les droits (art. XI.165 CDE)
- **Responsabilité** : limitation à un multiple du prix (ex: 2× le montant du contrat)

### 2. Conditions Générales de Vente (CGV)

**Structure minimale** :
1. **Identité du vendeur** : nom, adresse, BCE, TVA, contact
2. **Objet** : produits/services proposés
3. **Prix** : TTC, devise (€), modalités de paiement
4. **Commande** : processus, confirmation, rétractation (B2C : 14 jours)
5. **Livraison/exécution** : délais, modalités, transfert de risque
6. **Garantie** : légale (conformité, vices cachés) + commerciale éventuelle
7. **Réclamations** : procédure, délais
8. **Propriété intellectuelle** : droits sur les produits/services
9. **Protection des données** : renvoi vers politique de confidentialité
10. **Droit applicable** : droit belge
11. **Médiation/litige** : tribunal compétent, médiation préalable éventuelle

**Spécificités BE** :
- **B2C** : droit de rétractation de 14 jours (loi du 6 avril 2010)
- **B2B** : pas de droit de rétractation légal (sauf clause contractuelle)
- **Mentions obligatoires** : art. VI.45 Code de droit économique

### 3. Accord de confidentialité (NDA)

**Structure minimale** :
1. **Parties** : divulgateur / récepteur
2. **Définition des informations confidentielles** : liste ou description large
3. **Obligations du récepteur** : non-divulgation, usage limité, sécurité
4. **Exclusions** : informations publiques, déjà connues, développées indépendamment
5. **Durée** : typiquement 2-5 ans après la fin de la relation
6. **Conséquences de la violation** : dommages-intérêts, injonction
7. **Droit applicable** : droit belge

**NDA mutuel vs unilatéral** :
- **Unilatéral** : une seule partie divulgue (ex: tu présentes ton projet à un investisseur)
- **Mutuel** : les deux parties divulguent (ex: partenariat stratégique)

### 4. Mentions légales site web

**Obligatoires en Belgique** (art. XV.2 Code de droit économique) :
- Nom/dénomination du responsable du site
- Adresse de domicile/siège
- Numéro BCE
- Numéro TVA (si applicable)
- Email + téléphone (ou formulaire de contact)
- Nom de l'hébergeur
- Conditions d'utilisation du site

### 5. Accord de partenariat

**Structure minimale** :
1. **Parties** : partenaires
2. **Objet** : nature du partenariat (co-marketing, co-vente, intégration…)
3. **Durée** : déterminée ou indéterminée
4. **Obligations de chaque partie** : qui fait quoi, livrables, délais
5. **Rémunération** : commissions, partage de revenus, échanges
6. **Propriété intellectuelle** : droits sur les co-créations
7. **Exclusivité** : territoriale, sectorielle, ou non
8. **Résiliation** : conditions, préavis, conséquences
9. **Non-sollicitation** : ne pas débaucher les clients/employés de l'autre

## Checklist de vérification avant signature

Pour TOUT document juridique :
- [ ] Parties correctement identifiées (nom, adresse, BCE, qualité)
- [ ] Objet précis et non ambigu
- [ ] Prix/conditions de paiement clairs
- [ ] Durée et conditions de résiliation définies
- [ ] Propriété intellectuelle traitée (qui détient quoi)
- [ ] Responsabilité limitée (plafond raisonnable)
- [ ] Confidentialité définie (si applicable)
- [ ] Droit applicable et juridiction compétente
- [ ] RGPD traité (si données personnelles)
- [ ] Signature des deux parties (ou acceptation expresse)

## Common Pitfalls

1. **Copier un modèle internet sans l'adapter.** Un modèle générique ne couvre pas
   les spécificités belges (BCE, TVA, droit commercial). Toujours adapter.
2. **Oublier la propriété intellectuelle.** Sans clause, le prestataire détient les
   droits → le client n'a pas le droit d'utiliser les livrables comme il veut.
3. **Limitation de responsabilité absente.** Sans clause, la responsabilité est
   illimitée → un seul litige peut ruiner le solopreneur.
4. **Pas de préavis de résiliation.** Sans clause, la résiliation peut être abusive
   → toujours définir un préavis raisonnable (1-3 mois).
5. **Confondre CGV et contrat.** Les CGV s'appliquent aux ventes standard ; un contrat
   personnalisé prime sur les CGV en cas de conflit.
6. **Signer sans lire.** Chaque clause a une conséquence — lire, comprendre, et
   négocier les clauses critiques avant de signer.
